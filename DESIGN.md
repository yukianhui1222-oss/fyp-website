# DocuMind design direction

Adapted from https://github.com/voltagent/awesome-design-md/tree/main/design-md/claude.
Downloaded reference: docs/design/claude/DESIGN.md; MIT license: docs/design/LICENSE.
This is a design reference, not an installed Codex skill or official Anthropic guidance.

Preserve the original page gradients and panel backgrounds, as requested by the user.
Use charcoal text, generous spacing and restrained coral primary actions; do not replace the canvas with cream.
Use 16px or larger reading text. Keep visible keyboard focus and mobile padding.
Preserve DocuMind's rainbow title, stationery accents, folder tabs and floating assistants.
Use Georgia for the quiz welcome display only; retain readable sans-serif controls.
Use darker coral #a9583e for readable white CTA text. Do not copy the reference brand logo.
Implementation: the reference-inspired section at the end of ui_theme.css.
